This repository holds the data and the scripts that were used in the publication "Incorporating Multiple Bands and Land Cover Improves Cross-Sensor Normalization"
- The data in this repository are parquet versions of the CSV used to train and test the models.
- The XGB and RF models are located in .rar files, while the OLS and MLR models are located in text files. 
- If you are interested in a shapefile version with the point's lat/long, please contact the author of the paper.
- The scripts are in jupyter notebook format.
